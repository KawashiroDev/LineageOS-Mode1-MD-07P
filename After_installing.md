# After install

### Root:
Install SukiSU Nova's manager app from their releases - https://github.com/SukiSU-Nova/SukiSU-Nova/releases (The one that ends in arm64-v8a-release.apk)


### Camera:
Install Opencamera from F-Droid - https://f-droid.org/en/packages/net.sourceforge.opencamera/ 

Set it as the default camera application and set the resolution to 4624x3468 (16.04MP). Optionally enable "Show camera when locked" in Opencamera's settings (More camera controls > Show camera when locked) to allow it to launch from the lockscreen

The stock camera app works fine but the camera sensor takes pictures pixel binned to 16MP then upscaled to 64MP in low light
